# @viveksah/vibe-native-dicom

React Native library for DICOM parsing and rendering on iOS and Android

## Installation


```sh
npm install @viveksah/vibe-native-dicom
```


## Usage


```js
import { multiply } from '@viveksah/vibe-native-dicom';

// ...

const result = multiply(3, 7);
```
